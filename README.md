# Capturing Monetary Sovereignty: Replication Package

**Version v1.0.0 · 10 October 2026**

Start with [README.txt](README.txt) for the data guide, scope limitations and reproduction commands. The substantive evidence cutoff is 2 October 2026; later coding reviews and qualitative checks are documented separately.

This package reproduces Table 1, the rationale heatmap and the reported counts from the frozen recorded classifications. It provides source links and an audit trail for examining those classifications; computational reproduction does not establish independent recoding of the sources.
